# nhs-ae-performance-dashboard
Interactive Power BI dashboard analysing NHS Accident &amp; Emergency (A&amp;E) performance using June 2026 data.
NHS A&E Performance Dashboard
Project Overview

This project analyses NHS Accident & Emergency (A&E) performance using Power BI.

The dashboard provides an overview of:

Total A&E Attendances
Emergency Admissions
Patients Waiting Over Four Hours
Trust-level Performance Comparison

The goal is to transform healthcare data into actionable insights for operational decision-making.

Key Insights
Nearly 2.9 million patients attended NHS A&E departments in June 2026.
Approximately 27% of attendances resulted in emergency hospital admissions.
More than 1.1 million patients waited over four hours.
University Hospitals Birmingham NHS Foundation Trust recorded the highest number of patients waiting over four hours.
Significant variation exists across NHS Trusts, highlighting differences in demand and operational capacity.
Business Value

This dashboard enables healthcare managers to:

Monitor emergency service performance
Identify high-demand NHS Trusts
Track four-hour waiting targets
Support operational planning
Benchmark Trust performance
